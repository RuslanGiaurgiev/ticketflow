## Глоссарий

| Термин | Значение |
|---|---|
| **Мероприятие (Event)** | Концерт или спектакль с датой, площадкой и схемой зала |
| **Место (Seat)** | Конкретное кресло: сектор, ряд, номер. Продаётся не больше одного раза |
| **Холд (Hold / Reservation)** | Временная блокировка мест за заказом на 15 минут, пока покупатель платит |
| **Заказ (Order)** | Попытка покупки: набор мест, сумма, статус саги |
| **Билет (Ticket)** | Выпущенный документ с уникальным QR-кодом. Погашается на входе один раз |
| **Сага** | Длинный процесс из локальных транзакций в разных сервисах. Каждый шаг можно компенсировать |
| **Компенсация** | Действие, отменяющее эффект шага: освободить места, вернуть деньги |
| **Idempotency-Key** | Ключ запроса: повтор с тем же ключом не создаёт дубль |
| **Outbox / Inbox** | Таблицы в БД сервиса для надёжной отправки событий и для отсева повторно полученных |
